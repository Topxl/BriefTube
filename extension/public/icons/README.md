# Extension icons

Required sizes for Chrome Web Store & manifest:

- `icon-16.png`: toolbar (small)
- `icon-32.png`: toolbar (retina) + context menu
- `icon-48.png`: extension management page
- `icon-128.png`: Chrome Web Store listing

Generate from the main BriefTube logo (`/public/logo-120.png` in the web app).
Square, transparent background, red brand color `#dc2626` on the zap icon.
